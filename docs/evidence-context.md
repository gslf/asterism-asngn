# Evidence views and context selection

Large results are stored as content-addressed Asper objects after redaction.
The short view and every byte offset refer to these stored bytes, even when
ordinary context redaction is disabled. Invalid UTF-8 is rejected before a blob
is created. No auxiliary archive is created when Asper is disabled.

## Selecting a log view

The deterministic selector scans the entire result for bounded compiler, build,
traceback and test diagnostic markers. It keeps the first and most recent
diagnostic windows, merges overlaps and retains UTF-8 boundaries. Unknown formats
keep both head and tail. The default extractive view is at most 4 KiB, with at
most eight ranges and explicit omission notices.

`project.*` and `proc.*` results use this view directly, with no compressor call.
Other oversized results give the compressor a bounded 64 KiB selection rather
than a leading prefix. Recognized diagnostics are appended verbatim to a model
digest, so the compressor cannot remove them. The 4 KiB bound applies to the
extractive part; a model digest and source header add their own cost.

These are marker recognizers, not full parsers of every test framework or a
guarantee of diagnostic coverage. Dense logs can omit middle failures, and a
marker can occur in quoted source text. Views never create verification receipts
or change the task success gate. Full sources remain available for expansion.

## Opening a range

The action protocol requires an explicit object:

```text
{action: "open", why: "inspect the late failure", input: {"blob": 1, "offset": 80000}}
```

The native function `asterism_open` takes `{"blob":1,"offset":80000}`. Both fields
are required; unknown fields, negative offsets and unobserved handles are rejected.
The old string input `"B1"` is not accepted. Handles belong to the current session;
the header also includes the stable Asper object hash.

Reads return the source hash and `[start,end)` byte range, up to 32 KiB according
to the working budget. There is no hidden cursor. A reader can jump directly to
an excerpt, repeat a range, or continue from the returned end. Offsets must land
on UTF-8 boundaries. The exact source end returns EOF; an offset beyond it fails.

## Inspecting selection

`evidence_selection` telemetry identifies the source object, policy revision,
source and selected byte counts, marker count, range reasons and whether a
compressor supplied a digest. It contains no source text. Ranges describe the
extractive evidence, not a support mapping for every sentence generated by a model.

`context_selection` records the actual **assembled zones**: model, phase, observed
workspace snapshot, prompt hashes, fragment hashes and byte costs, admission
counts, and selection reasons. Current message, acceptance contract and phase
instructions are mandatory. Optional local evidence uses a recent suffix; local
history selects pinned turns and then recent turns that fit. Empty fragments have
zero byte cost. A trace describes at most 128 fragments, with explicit total and
omitted counts. Identical inputs produce identical prompt and trace bytes.

With Asper enabled, historical selection belongs to Asper. The trace identifies
the materialized memory blocks and marks local duplicates as delegated; it does
not pretend to explain Asper's individual event decisions. Native action history
and additional per-request schemas are also outside the assembled-zone trace.
This is selection observability, not yet the full repository evidence compiler.

Zone token attribution uses the configured text counter; its quality is not
preserved by that integer interface and the trace labels it unknown. Counts of
fragments are not additive. The complete request passes a separate model admission
check with conservative uncertainty reserves. The observed snapshot is a version reference, not an atomic claim that
every source was read at that instant.

Telemetry retains at most 8 MiB of event payload in the ring and batches at most
256 KiB before flushing. Events larger than 64 KiB are dropped. Existing rotation
and best-effort delivery apply; telemetry is not the durable action ledger.

Tests cover late errors beyond the old prefix, dense diagnostics, Unicode and
redaction offsets, explicit JSON/native ranges, invalid text, bounded traces,
actual llama.cpp grammar acceptance and whole-event file flushing under pressure.
Model quality, evidence recall and the selector's cost-benefit remain unmeasured.
